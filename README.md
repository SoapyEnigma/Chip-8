Supports:
- Windows
- Visual Studio 2022

Uses:
- C++20
- [GLFW 3.4](https://github.com/glfw/glfw)
- [GLAD (4.6 Core)](https://glad.dav1d.de/)
- [ImGui v1.92.2b - Docking](https://github.com/ocornut/imgui)
- [miniaudio](https://github.com/mackron/miniaudio)
- [Premake5](https://premake.github.io/)

How To Compile:
- Clone the repository
- Download and setup premake5
- In a console window, use the command `premake5 vs2022`
- Open the created .sln file and build the project.
